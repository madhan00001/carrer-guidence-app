# Career Profile: Cloud Engineer

## 1. Role Overview
A Cloud Engineer plans, develops, monitors, and optimizes cloud computing infrastructure and services across providers like AWS, Google Cloud (GCP), or Microsoft Azure.

## 2. Core Responsibilities
- Architect high-availability, fault-tolerant, and secure cloud infrastructures.
- Provision and manage cloud resources via Infrastructure as Code (Terraform, CloudFormation).
- Configure virtual private clouds (VPCs), subnets, routing tables, and security groups.
- Optimize cloud expenditures (FinOps) and implement auto-scaling policies.
- Ensure disaster recovery and automated backup strategies.

## 3. Required Technical Skills & Languages
- **Cloud Providers:** AWS (EC2, S3, RDS, IAM, Lambda, ECS, CloudFront) or Google Cloud / Azure.
- **Infrastructure as Code (IaC):** Terraform, Ansible, AWS CloudFormation.
- **Operating Systems & Scripting:** Linux administration (Ubuntu/RHEL), Bash scripting, Python.
- **Networking:** DNS, CIDR blocks, TCP/IP, VPNs, Load Balancing, CDN.
- **Security & Identity:** IAM roles/policies, KMS encryption, OAuth2, Zero-Trust fundamentals.
- **Containers:** Docker, Kubernetes basics.

## 4. Required Soft Skills
- Incident management and calm temperament during service degradation.
- Cross-functional communication with developers and security teams.
- Cost-conscious engineering and capacity planning mindset.

## 5. Industry Certifications
- AWS Certified Solutions Architect - Associate (SAA-C03)
- Google Cloud Associate Cloud Engineer (ACE)
- Microsoft Certified: Azure Fundamentals / Administrator Associate (AZ-104)
- HashiCorp Certified: Terraform Associate

## 6. Recommended Learning Resources & Courses
- Stephane Maarek AWS Solutions Architect Course (Udemy)
- Adrian Cantrill Cloud Architect learning tracks
- "Terraform: Up & Running" by Yevgeniy Brikman
- AWS Well-Architected Framework whitepapers

## 7. Recommended Portfolio Projects
1. **Multi-Tier Highly Available Web Application on AWS:** Automated Terraform project deploying VPC, Application Load Balancer, Auto-Scaling Group, and multi-AZ RDS.
2. **Serverless Image Processing Pipeline:** Event-driven architecture using S3 bucket triggers, AWS Lambda, DynamoDB, and SNS notifications.
3. **Cloud Cost Monitoring & Alerting Bot:** Python script polling CloudWatch/Cost Explorer to flag anomalous spending spikes via Slack webhook.

## 8. Interview Topics & Preparation Checklist
- High-availability vs fault tolerance, recovery time objective (RTO) vs recovery point objective (RPO).
- Designing a 3-tier VPC with public, private, and database subnets.
- IAM least-privilege policies, cross-account access, and security groups vs NACLs.
- Live Terraform syntax and state locking mechanisms.
