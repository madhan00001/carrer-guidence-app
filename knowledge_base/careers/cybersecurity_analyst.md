# Career Profile: Cybersecurity Analyst

## 1. Role Overview
A Cybersecurity Analyst safeguards an organization's proprietary data, networks, cloud environments, and digital infrastructure against unauthorized intrusions, malware, security breaches, and vulnerabilities.

## 2. Core Responsibilities
- Monitor security information and event management (SIEM) consoles for anomalous activity.
- Conduct vulnerability assessments and simulated penetration tests.
- Formulate and execute incident response playbooks during suspected breaches.
- Enforce identity security policies, multi-factor authentication (MFA), and patch cadence.
- Train enterprise personnel on phishing detection and digital hygiene.

## 3. Required Technical Skills & Languages
- **Network Security:** Wireshark, Nmap, TCP/IP handshake, firewalls, IDS/IPS, VPN protocols.
- **SIEM & Log Analysis:** Splunk, Microsoft Sentinel, ELK Stack (Elasticsearch, Logstash, Kibana).
- **Vulnerability Management:** Nessus, Qualys, OWASP Top 10 web vulnerabilities.
- **Operating Systems & Scripting:** Linux security hardening, Windows Event logs, Python, Bash, PowerShell.
- **Frameworks & Compliance:** NIST Cybersecurity Framework, MITRE ATT&CK matrix, ISO 27001, GDPR.

## 4. Required Soft Skills
- Forensic meticulousness and pattern detection under pressure.
- Discretion, ethics, and strict handling of confidential information.
- Clear technical writeups translating security threats into business risks.

## 5. Industry Certifications
- CompTIA Security+ (SY0-701) - the premier entry-level gold standard
- Certified Information Systems Security Professional (CISSP) - career milestone
- Certified Ethical Hacker (CEH) or CompTIA CySA+
- GIAC Security Essentials (GSEC)

## 6. Recommended Learning Resources & Courses
- TryHackMe / Hack The Box hands-on security labs
- Professor Messer CompTIA Security+ video training
- OWASP Top 10 Interactive Vulnerabilities Guide
- "The Practice of Network Security Monitoring" by Richard Bejtlich

## 7. Recommended Portfolio Projects
1. **Home Lab SIEM & Threat Hunting Arena:** Virtualized Active Directory lab forwarding logs into a Splunk instance with custom correlation alert rules.
2. **Automated Vulnerability Scanner & Report Generator:** Python script scanning local IPs for open ports, unpatched services, and compiling an executive PDF briefing.
3. **Phishing Simulation & Defensive Analysis:** Controlled test assessing header indicators, SPF/DKIM/DMARC records, and malicious payload analysis in a sandbox.

## 8. Interview Topics & Preparation Checklist
- Walkthrough of the CIA Triad (Confidentiality, Integrity, Availability) and defense-in-depth.
- Explanation of OWASP Top 10 (SQL Injection, XSS, CSRF, Broken Access Control).
- Incident response lifecycle: Preparation, Identification, Containment, Eradication, Recovery, Lessons Learned.
- How to analyze a suspicious PCAP packet capture file using Wireshark.
